# আনসেন্সরড এজেন্ট (ফোনে, অফলাইন)

নিজের ফোনে চলা একটা চ্যাট এজেন্ট। মডেল ফোনেই চলে, ইন্টারনেট লাগে না,
কোনো ক্লাউড ফিল্টার নেই।

## একবার সেটআপ (Termux)

```bash
pkg install -y git
git clone <এই-রেপোর-লিংক> ~/uncensored-agent
cd ~/uncensored-agent && bash setup.sh
```

`setup.sh` যা করে: প্যাকেজ ইনস্টল → llama.cpp বিল্ড → Qwen2.5-3B-Instruct-abliterated
(Q4_K_M, ~২ GB) ডাউনলোড।

## চালানো

```bash
bash ~/uncensored-agent/start.sh
```

প্রথমবার মডেল লোড হতে ৩০-৬০ সেকেন্ড। এরপর `আপনি:` প্রম্পটে লিখুন।
বের হতে `/bye`, নতুন আলোচনার জন্য `/reset`।

## নিজের মতো সাজানো

```bash
python3 agent.py --system "তুমি একজন রাজনৈতিক কনটেন্ট লেখক, বাংলায় লেখো" --temp 0.9
```

## ফোনে টিপস

- ৪ GB RAM থাকলে মডেলটা আরামে চলবে; ৩ GB-তে `-c 2048` করে নিন (start.sh-এ)।
- `termux-wake-lock` দেওয়া আছে, তবু Termux-কে Battery → Unrestricted রাখুন।
- মডেল বদলাতে চাইলে `~/models/`-এ নতুন GGUF রাখুন আর start.sh-এ নাম বদলান।

## অন্য মডেল (যদি আরও শক্তিশালী চান)

| মডেল | সাইজ | ফোনে গতি |
|---|---|---|
| Qwen2.5-3B-Instruct-abliterated Q4_K_M | ~২ GB | দ্রুত |
| Dolphin3.0-Qwen2.5-3B Q4_K_M | ~২ GB | দ্রুত |
| Qwen2.5-7B-Instruct-abliterated Q4_K_M | ~৪.৫ GB | ধীর (৬-৮ GB RAM দরকার) |


## প্রিসেট (তৈরি প্রম্পট)

```bash
bash start.sh                    # সাধারণ চ্যাট
bash start.sh --preset writer    # আওয়ামী লীগ-পন্থী রাজনৈতিক পোস্ট লেখক
bash start.sh --preset caption   # ফেসবুক ক্যাপশন লেখক
bash start.sh --preset script    # ৪৫ সেকেন্ডের রিলস স্ক্রিপ্ট
```

নিজের প্রম্পট বানাতে `prompts.json`-এ নতুন কী যোগ করুন, তারপর `--preset <নাম>`।
মডেল কোনো নেতার নামে বানানো উক্তি বা ভুয়া তথ্য লিখবে না — এই নিয়ম প্রম্পটেই বসানো।


## টুলসহ এজেন্ট (সোলাসের মতো, কিন্তু আনসেন্সরড)

শুধু চ্যাট নয় — এজেন্টটা নিজে টুল ব্যবহার করতে পারে: শেল, ফাইল পড়া/লেখা,
ওয়েব থেকে লেখা আনা, আর মেমোরি (`memory.json`)।

```bash
bash start.sh --tools                     # টুলসহ টার্মিনাল এজেন্ট
bash start.sh --tools --preset writer     # রাজনৈতিক লেখক মোড
```

প্রথমবার একটা লম্বা কাজ দিন, যেমন: "আমার Downloads ফোল্ডারে কী আছে দেখো,
তারপর একটা সারাংশ লেখো।" এজেন্ট নিজে `run_shell` ডাকবে, ফল দেখে উত্তর দেবে।

### Telegram থেকে চালানো

BotFather → `/newbot` → টোকেন নিন, তারপর:

```bash
export TELEGRAM_BOT_TOKEN=আপনার-টোকেন
export TELEGRAM_ALLOWED=আপনার-chat-id      # /start দিলে দেখাবে
python3 telegram.py
```

এখন ফোন যেখানেই থাকুক, Telegram থেকে এজেন্টকে কাজ দিতে পারবেন।

### কী কী বদলেছে (সোলাসের সাথে তুলনা)

| বিষয় | সোলাস | এই এজেন্ট |
|---|---|---|
| মডেল | ক্লাউড (বড়) | ফোনে ৩B/৭B |
| সেন্সর | প্ল্যাটফর্মের নিয়ম | মডেলেই নেই (abliterated) |
| টুল | অনেক | ৫টা (শেল, ফাইল×২, ওয়েব, মেমোরি) |
| ইন্টারনেট | লাগে | লাগে না |
| খরচ | ক্রেডিট | শূন্য |

সীমা: ৩B মডেল টুল বেছে নিতে ভুল করে। ৬-৮ GB RAM থাকলে ৭B ব্যবহার করুন —
`qwen2.5-7b-instruct-abliterated` GGUF, নিচের কমান্ডে নাম বদলালেই হবে।
